# Limbus Company 社区资源导航

收集《Limbus Company》常用的 Wiki、自动化脚本、本地化项目和社区工具，方便快速查找。

> [!IMPORTANT]
> 本列表中的项目大多由社区维护，与 Project Moon 无关。使用自动化、Mod 或第三方本地化前，请自行阅读项目说明、许可证与游戏服务条款，并备份重要文件。项目可能停止维护，下载前请检查最近提交、Release 和 Issue。
